# 🎲 Jarvis 3x3 魔方游戏

一个精美的 3D 魔方游戏，带有 AI 提示系统。

## ✨ 功能特性

- **🎨 精美 UI** - 现代渐变背景，玻璃拟态设计
- **🔀 打乱功能** - 一键打乱魔方
- **🤖 AI 提示** - 本地求解器 + MiniMax AI 解释
- **🎉 胜利庆祝** - 彩色纸屑动画
- **📊 统计记录** - 步数、耗时、提示次数

## 🚀 在线体验

**GitHub Pages:** https://your-username.github.io/rubiks-cube-game/

**或直接打开:** `index.html`

## 🎮 操作说明

1. 点击 **🔀 打乱** 开始游戏
2. 使用右侧按钮旋转各层
3. 点击 **💡 AI 提示** 获取帮助
   - 本地算法给出下一步
   - MiniMax AI 解释为什么
4. 复原魔方后庆祝！
